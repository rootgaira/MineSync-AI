🔍 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"ModuleNotFoundError: No module named 'fitz'"
  → Run: pip install PyMuPDF

"Tesseract is not installed"
  → Not required, PaddleOCR is the fallback
  → Or install from: https://github.com/UB-Mannheim/tesseract/wiki

"PaddleOCR stuck on first run"
  → It's downloading the model (~50MB), this is normal
  → Wait 1-2 minutes on first run

"No text extracted"
  → Image quality may be poor
  → Try uploading a higher resolution image
